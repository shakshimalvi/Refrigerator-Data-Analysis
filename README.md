# Refrigerator Data Analysis | Web Scraping & EDA

A complete **End-to-End Data Analysis** project focused on refrigerators sold on **Amazon India**. This project demonstrates web scraping, data cleaning, feature engineering, and insightful visualizations using Python.

### 📌 Project Objective

The goal of this project is to scrape real-time refrigerator data from Amazon.in across multiple categories (Single Door, Double Door, Side-by-Side, etc.), clean and transform the data, and perform Exploratory Data Analysis (EDA) to uncover pricing trends, brand performance, and feature-wise insights.

### ✨ Key Features

- **Web Scraping** from 7 refrigerator categories (405+ products collected)
- **Data Cleaning & Pre-processing**
- **Feature Engineering**:
  - Star Rating extraction
  - Fridge Type (Single/Double/Side-by-Side)
  - Cooling Type (Direct Cool / Frost Free)
  - Inverter vs Non-Inverter
  - Convertible, Smart, Water Dispenser flags
  - Price Range categorization
- **Exploratory Data Analysis** with visualizations
- **Correlation Analysis**

### 🛠️ Technologies Used

- **Python**
- **BeautifulSoup + Requests** (Web Scraping)
- **Pandas** (Data Manipulation)
- **Matplotlib & Seaborn** (Visualization)
- **Regular Expressions** (Feature Extraction)

### 📊 Dataset Overview

- **Total Products**: 405
- **Columns**: Product Name, Brand, Price, Compressor, Capacity, Star Rating, Fridge Type, Cooling Type, Convertible, Smart, etc.
- **Categories Scraped**:
  - Single Door
  - Double Door
  - Side by Side
  - Frost Free
  - Mini
  - Smart
  - Inverter

### 📈 Key Visualizations

- Price distribution by Compressor Type (Inverter vs Non-Inverter)
- Correlation Heatmap between Capacity, Rating & Price
- Brand-wise analysis
- Price Range segmentation
